یک راهنمای کوتاه و مرتب برای شروع پایتون. از منوی بالا هر مبحث را بزن تا به صفحه‌ی مخصوص خودش بروی؛ هر صفحه رنگ و حال‌وهوای خودش را دارد.

پایتون چیست؟

پایتون یک زبان برنامه‌نویسی ساده و قدرتمند است که در سال ۱۹۹۱ توسط گیدو ون روسوم ساخته شد. نوشتنش شبیه جمله‌های انگلیسی است و برای شروع عالی است.

  • توسعه وب، اتوماسیون و اسکریپت‌نویسی
  • تحلیل داده و علم داده
  • بازی‌سازی، ابزارهای دسکتاپ و امنیت

نصب پایتون

  • به سایت python.org بخش Downloads برو و آخرین نسخه را بگیر.
  • در ویندوز گزینه Add Python to PATH را تیک بزن.
  • برای تست، در ترمینال بنویس:
python --version

برای نوشتن کد می‌توانی از IDLE، VS Code یا PyCharm استفاده کنی.

اولین برنامه

تابع print هر چیزی را نمایش می‌دهد و # برای توضیح (کامنت) است.

# اولین برنامه
print("Hello, World!")

name = input("اسمت چیه؟ ")
print("سلام", name)

متغیرها

متغیر یک جعبه‌ی نام‌دار است که مقدار را نگه می‌دارد و نیازی به تعیین نوع ندارد.

age = 20
name = "Sara"
price = 9.5
age = age + 1
  • نام متغیر با عدد شروع نمی‌شود و فاصله ندارد.
  • حروف بزرگ و کوچک فرق دارند.
  • از سبک snake_case استفاده کن: my_name

رشته‌ها (متن)

s = "python"
print(len(s))        # 6
print(s.upper())     # PYTHON
print(s[0], s[-1])   # p n
print(s[1:4])        # yth
print(f"Hi {s}!")    # f-string

شرط‌ها

تورفتگی ابتدای خط در پایتون مهم است و بلوک کد را مشخص می‌کند.

score = 85
if score >= 90:
    print("عالی")
elif score >= 60:
    print("قبول")
else:
    print("مردود")

حلقه‌ها

for i in range(5):     # 0 تا 4
    print(i)

n = 3
while n > 0:
    print(n)
    n -= 1

با break از حلقه خارج می‌شوی و با continue دور فعلی را رد می‌کنی.

تابع‌ها

تابع بخشی از کد است که یک بار می‌نویسی و هر چندبار صدا می‌زنی.

def add(a, b=0):
    return a + b

print(add(2, 3))   # 5
square = lambda x: x * x

ماژول‌ها و کتابخانه‌ها

import math
print(math.sqrt(16))   # 4.0

from random import randint
print(randint(1, 10))

کار با فایل

with open("note.txt", "w", encoding="utf-8") as f:
    f.write("سلام")

with open("note.txt", "r", encoding="utf-8") as f:
    print(f.read())

حالت‌ها: r خواندن، w نوشتن، a اضافه‌کردن.

مدیریت خطا

try:
    x = int(input("عدد: "))
    print(10 / x)
except ValueError:
    print("عدد معتبر وارد کن")
except ZeroDivisionError:
    print("تقسیم بر صفر ممکن نیست")
finally:
    print("پایان")

آشنایی با شی‌گرایی

کلاس یک قالب است و شیء نمونه‌ای ساخته‌شده از آن قالب.

class Cat:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(self.name, "میومیو")

Cat("Mini").speak()

نکات و مسیر یادگیری

  • هر روز کمی کد بنویس؛ تمرین از حفظ‌کردن مهم‌تر است.
  • پیام خطا را با دقت بخوان، معمولاً راه حل را می‌گوید.
  • پروژه‌ی کوچک بساز: ماشین‌حساب، حدس عدد، لیست کارها.
  • با help(print) راهنمای هر تابع را ببین.
  • بعد از مبتدی: pandas، Flask و Django.
