یک راهنمای کوتاه و مرتب برای شروع پایتون. از منوی بالا هر مبحث را بزن تا به صفحه‌ی مخصوص خودش بروی؛ هر صفحه رنگ و حال‌وهوای خودش را دارد.

پایتون چیست؟

پایتون یک زبان برنامه‌نویسی ساده و قدرتمند است که در سال ۱۹۹۱ توسط گیدو ون روسوم ساخته شد. نوشتنش شبیه جمله‌های انگلیسی است و برای شروع عالی است.

  • توسعه وب، اتوماسیون و اسکریپت‌نویسی
  • تحلیل داده و علم داده
  • بازی‌سازی، ابزارهای دسکتاپ و امنیت

نصب پایتون

  • به سایت python.org بخش Downloads برو و آخرین نسخه را بگیر.
  • در ویندوز گزینه Add Python to PATH را تیک بزن.
  • برای تست، در ترمینال بنویس:
python --version

برای نوشتن کد می‌توانی از IDLE، VS Code یا PyCharm استفاده کنی.

اولین برنامه

تابع print هر چیزی را نمایش می‌دهد و # برای توضیح (کامنت) است.

# اولین برنامه

name = input("اسمت چیه؟ ")
print("سلام", name)

متغیرها

متغیر یک جعبه‌ی نام‌دار است که مقدار را نگه می‌دارد و نیازی به تعیین نوع ندارد.

age = 20
name = "Sara"
price = 9.5
age = age + 1
  • نام متغیر با عدد شروع نمی‌شود و فاصله ندارد.
  • حروف بزرگ و کوچک فرق دارند.
  • از سبک snake_case استفاده کن: my_name

عملگرها

اولویت اجرا: ابتدا **، بعد * / // %، بعد + -، بعد مقایسه‌ها و در آخر not، and، or. برای شک نکردن از پرانتز استفاده کن.

print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20
x = 10
x += 5               # x = x + 5
print(x > 3 and x < 20)   # True

حلقه‌ها

for i in range(5):     # 0 تا 4
    print(i)

n = 3
while n > 0:
    print(n)
    n -= 1
for i, name in enumerate(["a", "b"], start=1):
    print(i, name)          # 1 a  /  2 b

for i in range(1, 4):
    for j in range(1, 4):   # حلقه تو در تو
        print(i * j, end=" ")
    print()

for i in range(10):
    if i == 3:
        continue
    if i == 6:
        break
    print(i)

با break از حلقه خارج می‌شوی و با continue دور فعلی را رد می‌کنی.

تابع‌ها

تابع بخشی از کد است که یک بار می‌نویسی و هر چندبار صدا می‌زنی.

def add(a, b=0):
    return a + b

print(add(2, 3))   # 5
square = lambda x: x * x
def total(*nums):          # تعداد ورودی دلخواه
    return sum(nums)

def info(**kw):            # ورودی‌های نام‌دار
    print(kw)

print(total(1, 2, 3))      # 6
info(name="Ali", age=9)

def div(a, b):
    """تقسیم دو عدد"""      # docstring: توضیح تابع
    return a / b, a // b   # چند مقدار برگشتی

q, r = div(7, 2)

متغیری که داخل تابع ساخته شود فقط همان‌جا دیده می‌شود (محدوده‌ی محلی).

آشنایی با شی‌گرایی

کلاس یک قالب است و شیء نمونه‌ای ساخته‌شده از آن قالب.

class Cat:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(self.name, "میومیو")

Cat("Mini").speak()

نکات و مسیر یادگیری

  • هر روز کمی کد بنویس؛ تمرین از حفظ‌کردن مهم‌تر است.
  • پیام خطا را با دقت بخوان، معمولاً راه حل را می‌گوید.
  • پروژه‌ی کوچک بساز: ماشین‌حساب، حدس عدد، لیست کارها.
  • با help(print) راهنمای هر تابع را ببین.
  • بعد از مبتدی: pandas، Flask و Django.

توابع آماده پایتون

پایتون ده‌ها تابع آماده دارد که بدون import کار می‌کنند.

تابعکار
len(x)تعداد اعضا یا حروف
sum(x)جمع اعضا
min / maxکوچک‌ترین و بزرگ‌ترین

for a, b in zip([1, 2], ["x", "y"]):

لیست‌نویسی فشرده

List comprehension راهی کوتاه برای ساختن لیست در یک خط است.

squares = [x * x for x in range(1, 6)]
print(squares)                  # [1, 4, 9, 16, 25]

evens = [x for x in range(10) if x % 2 == 0]
print(evens)                    # [0, 2, 4, 6, 8]

words = ["a", "bb", "ccc"]
lens = {w: len(w) for w in words}   # دیکشنری فشرده
print(lens)

unique = {x % 3 for x in range(10)}  # مجموعه‌ی فشرده

برش لیست‌ها (Slicing):

a = [10, 20, 30, 40, 50]
print(a[1:4])    # [20, 30, 40]
print(a[::2])    # [10, 30, 50]
print(a[::-1])   # برعکس

تمرین‌ها

اول خودت حل کن، بعد جواب را ببین.

  • ۱. برنامه‌ای بنویس که نام و سن بگیرد و بگوید ده سال دیگر چند ساله‌ای.
  • ۲. زوج یا فرد بودن یک عدد را تشخیص بده.
  • ۳. اعداد ۱ تا ۱۰۰ را جمع بزن.
  • ۴. بزرگ‌ترین عدد در یک لیست را بدون max پیدا کن.
  • ۵. جدول ضرب یک عدد را چاپ کن.
  • ۶. بررسی کن یک متن پالیندروم (مثل level) هست یا نه.
  • ۷. تعداد حروف صدادار یک جمله را بشمار.
  • ۸. تابعی بنویس که فاکتوریل بگیرد.

جواب تمرین‌های ۲، ۳ و ۶:

n = int(input())
print("even" if n % 2 == 0 else "odd")

print(sum(range(1, 101)))   # 5050

s = "level"
print(s == s[::-1])         # True

پروژه‌های کوچک

۱. بازی حدس عدد:

import random
secret = random.randint(1, 20)
while True:
    g = int(input("Guess: "))
    if g < secret:
        print("higher")
    elif g > secret:
        print("lower")

۲. لیست کارها:

tasks = []
while True:
    cmd = input("add / show / quit: ")
    if cmd == "add":
        tasks.append(input("Task: "))
    elif cmd == "show":
        for i, t in enumerate(tasks, 1):
            print(i, t)

۳. ماشین‌حساب ساده:

a = float(input("a: "))
op = input("+ - * / : ")
b = float(input("b: "))
if op == "+": print(a + b)
elif op == "-": print(a - b)
elif op == "*": print(a * b)
elif op == "/": print(a / b if b else "error")

خطاهای رایج

خطا دشمن تو نیست؛ دقیقاً می‌گوید مشکل کجاست. خط آخر پیام را بخوان.

خطامعنی و راه حل
SyntaxErrorنوشتار اشتباه؛ : یا پرانتز را چک کن
IndentationErrorتورفتگی نادرست؛ ۴ فاصله بگذار
NameErrorمتغیر تعریف نشده یا غلط تایپی
TypeErrorنوع‌ها نمی‌خوانند (مثلاً عدد + متن)
ValueErrorمقدار نامناسب، مثل int("abc")
IndexErrorشماره‌ی خارج از لیست
KeyErrorکلید در دیکشنری نیست؛ از get استفاده کن
ZeroDivisionErrorتقسیم بر صفر
if x = 5:      # اشتباه: = یعنی مقداردهی
if x == 5:     # درست: == یعنی مقایسه

print("age: " + 20)        # TypeError
print("age: " + str(20))   # درست

input("n: ") + 1           # ورودی همیشه متن است
int(input("n: ")) + 1      # درست
